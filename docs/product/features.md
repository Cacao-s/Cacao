# Cacao — 功能規格

> 狀態：已定案（2026-10-05）
> 標示「第二版」的項目不在第一版範圍，見 [roadmap.md](roadmap.md)。

---

## 裝置與身分

- **第一版全家共用一台手機**，資料只存在這台手機。
- App 有兩種模式：
  - **父母模式**：先選擇孩子，再管理該孩子的存款、出金、任務、目標。
  - **孩子模式**：進入該孩子的錢包首頁。
- **父母驗證碼（PIN）**：
  - 每位父母各有一組，在設定時建立。
  - 用途：從孩子模式進入父母模式、驗證任務、保護只有父母能用的功能。
- **孩子密碼（選填）**：每個孩子可以自己決定要不要設；有設的話進入該孩子的畫面要輸入。忘記時由父母重設。父母模式不受孩子密碼限制。
- 不做帳號密碼登入。Google 登入只用於備份（見[備份與還原](#備份與還原)）。
- 支援多個孩子、兩位父母共管（第一版共用同一台手機）、只有一位管理者。

### 角色權限

| 功能 | 父母 | 孩子 |
| --- | --- | --- |
| 記收入、出金 | ✓ | — |
| 看存款與目標 | ✓ | ✓ |
| 建立、刪除目標 | ✓ | ✓ |
| 確認目標「已達成」 | — | ✓ |
| 建立任務 | ✓（含代長輩） | — |
| 回報任務完成 | — | ✓ |
| 驗證任務 | ✓ | — |
| 記錢包支出 | ✓（修正） | ✓ |
| 校正錢包餘額 | ✓ | ✓ |

## 帳戶模型

每個孩子有兩個帳戶：

- **存款**：父母保管的錢。只有父母能記。
- **錢包**：孩子手上的錢。出金後的錢進錢包。

金額規則：

- 只支援新台幣，金額為整數。
- **可出金額 = 存款 − 已鎖金額**（已鎖金額見[儲蓄目標](#儲蓄目標)）。
- **不支援預支／借款**：出金最多到可出金額，存款不會變成負數。想用鎖在目標裡的錢，由孩子自己把目標退回「進行中」解鎖。預支／借款列入[第二版以後](roadmap.md#第二版以後)評估。

## 收入

- **常態零用錢**：
  - 自動定期入帳（例如每週一 100 元）。實作上是開啟 App 時補記到期款項。
  - 週期：每天、每週、每兩週、每月。每週與每兩週可選星期幾，每月可選幾號（選 29～31 號遇到小月份時，在當月最後一天發）。
  - 每個孩子金額可以不同，可以隨時調整（之後照新金額發），可以暫停。
  - 長輩也可以有常態零用錢（例如「外婆每月 500」），由父母代為設定。
- **一次性收入**：過年紅包、生日、成績獎勵等，由父母記錄，並標示來源（父母或某位長輩）。
- **長輩直接塞現金給孩子**：父母當下決定怎麼記，兩種都支援：
  - 記一筆收入進存款，現金由父母收走保管。
  - 記一筆收入，但現金留在孩子手上，所以同時記一筆出金到錢包。
- **指定給目標的錢**：
  - 長輩給的錢可以指定給某個目標，直接算進該目標，不參與瀑布填充；超過目標金額的部分回到存款池，參與瀑布填充。
  - 父母加碼時可以選擇要不要指定目標；指定了就直接算進該目標。
- **任務獎勵**：任務驗證通過後自動入帳（見[任務](#任務)）。

---

## 出金

- 由父母記錄，從存款扣除，錢進孩子的錢包。
- 一般出金可以選擇關聯一個「已達成」的目標（見[目標出金](#目標出金)）。
- 已鎖住的錢不能用於一般出金。

---

## 錢包

- 錢包記帳是**孩子的自由**：可以記、也可以不記，App 不強制、不提醒。
- 父母看得到，也可以修正；不做隱私設定。
- 顯示錢包餘額（出金總額 − 已記支出）。
- **校正餘額**：輸入實際剩多少，差額記成一筆「未記錄支出」。

---

## 任務

- **只有父母（含代長輩）能建立任務**，孩子不能提議。
- 獎勵**只有錢**，不做點數、貼紙等非金錢獎勵。
- 流程：孩子在孩子模式按「完成」→ 畫面直接要求父母輸入驗證碼，當場驗收 → 獎勵自動入帳。
  - 沒有「待驗證」狀態：父母覺得沒做好就不輸入，任務維持「待完成」，不留紀錄。
- 第一版：**一次性任務**。
- 第二版：
  - **重複任務**：每天、每週、自訂（例如每週一三五）。
  - **有期限的任務**：過期後標記「已過期」並保留在紀錄裡；父母可以延長期限。
  - **可部分完成的任務**（例如「讀 10 本書」）：全部完成後才驗證，一次發放獎勵。
  - 父母在自己的手機上直接核准（需要裝置同步）。

## 儲蓄目標

- 可以多個目標同時進行；孩子和父母都能建立、刪除。
- **瀑布式填充**：
  - 目標有優先順序，存款從最優先的目標開始往下填。
  - 可以拖曳調整順序。
  - 可以取消勾選某個目標，讓它暫時不參與填充，把錢讓給下一個。
  - 指定給某目標的錢直接算進該目標，不參與瀑布。
- **目標金額**：只有「進行中」的目標可以修改；「已達成」要先退回「進行中」才能改。

### 狀態

```text
進行中 ──(填滿)──> 可達成 ──(孩子確認)──> 已達成【鎖錢】──(父母出金)──> 已完成
 ^ ^                  │                        │
 │ └─(存款不夠填滿)───┘                        │
 └────────────────(孩子反悔，解鎖)─────────────┘
```

- **進行中**：不鎖錢。一般出金會減少存款，各目標進度跟著重算。
- **可達成**：已填滿，等孩子確認。還沒鎖錢；存款變少、不夠填滿時自動回到「進行中」。
- **已達成**：由孩子確認後鎖錢。可以退回「進行中」（孩子反悔，想先完成別的目標）。
- **已完成**：父母出金後自動進入。不能退回；出金記錯時把那筆出金作廢，目標回到「已達成」，錢仍然鎖住。

### 目標出金

- 兩種入口：從「已達成」的目標直接按「出金」，或在一般出金畫面選擇關聯一個已達成的目標。
- 出金後目標自動變成「已完成」，錢進孩子的錢包。
- 實際價格和目標金額常常不同：
  - **比目標高**（目標 3000，實際 3480）：目標其實沒達成。由孩子手動退回「進行中」、修改目標金額，繼續存。
  - **比目標低**（特價 2800）：出金以實際輸入的金額為準；剩下的錢解鎖、回到存款，重新瀑布填充。

## 互動

都不需要裝置同步，第一版就做：

- **任務的來回**：孩子回報完成 → 父母驗證 → 錢入帳，每一步都有清楚的回饋。
- **達成的慶祝**：存到目標、任務驗證通過時，有動畫或音效。
- **長輩的存在感**：長輩給錢時顯示成「爺爺給你 500」的卡片，可以附一句話。
- **成長紀錄（簡單版）**：一年累計存了多少、完成幾個任務。完整的定期回顧報表（圖表、趨勢）在第二版。

不做：推播通知、孩子申請花錢、父母留言鼓勵。

## 備份與還原

- **Google 雲端硬碟備份**（第一版必做）：
  - Google 登入的唯一用途是備份。
  - 備份存在使用者自己的 Google 雲端硬碟；App 核心功能不依賴它，沒網路照常使用。
  - 換手機時可以從 Google 備份還原。
- **沒登入 Google 也能使用 App**：備份功能關閉，App 會提醒「目前沒有備份」。
- **匯出／匯入備份檔**：給沒有 Google 帳號、或不想連 Google 的家庭，自己保存備份檔。
